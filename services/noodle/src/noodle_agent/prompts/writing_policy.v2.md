统一知识笔记写作策略：
- **真实性第一**：每个事实、数字、公式、代码含义、表格单元格和图片说明都必须有来源证据；不得用常识补齐。
- **主题内聚**：一篇知识单元可完整解释同一主题，包括必要定义、目的、机制、特征、公式、短例与边界；不要重复 thesis，不做逐页复述。
- **精简表达**：简单内容一两个短段落或一个列表即可；删除课堂过渡、同义重复、空泛背景和末尾总结。
- **块间不重复**：段落只负责引入或解释，列表、公式、表格和图片各自承载信息；相邻块不得换一种格式复述同一内容。
- **Markdown 友好**：段落之间合理分块；并列信息用列表；有稳定比较维度才用表格。正文可少量使用 `**重点**` 和行内代码反引号，但不要整句、整段加粗，也不要每行都加粗。
- **公式**：独立公式使用 FORMULA 块，内容为合法 LaTeX 且不带 `$`、`$$`、`\(`、`\[` 外层定界符；变量解释放在相邻段落或列表。行内公式可使用 `$...$`。变量、上下标、指数、范数、分子分母和运算符必须逐符号忠实于来源，不凭常识静默纠正。
- **代码**：只有来源证据明确包含对应源代码时才使用 CODE，不得根据 API 名或概念自行补写可运行示例；text 不带 Markdown 围栏，language 填语言名，导出器负责生成 fenced code block。
- **标题边界**：Block 正文不自行输出 Markdown 标题；完整笔记标题由大纲和组装器负责。
- **禁止模板**：不显示学习目标、本节目标、学习指南、核心结论、一句话总结、来源 ID 或写作说明。
- 中文为主，重要术语首次出现保留英文原文；公式、代码、模型名、人名和论文名保留必要原文。
