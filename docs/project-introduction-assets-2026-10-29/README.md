每图保留三个文件：`.html` 为自包含绘制源，`.svg` 为 Markdown 插图，`.mmd` 为可编辑逻辑源。SVG 从 HTML 通过指定 Diagram Design 技能的 `export_svg.py --system-fonts` 导出，没有从 Mermaid 自动布局截图。

图示使用技能的连接几何和语义色原则，按用户明确要求省略可见标题、分组装饰框与底部图例；文字解释放回 Markdown。图 04 保留 12 个关键组件，其余图每张不超过 9 个节点。白底为本轮简洁文档插图的呈现选择，橙色为既定重点色。

图 04 合并“用户”和“Web 工作台”入口；独立 DSH 也可直接接收用户交互。没有把会话桥画成第二套 Python Agent Loop。为控制连线密度，图中只集中画出 Worker 到解析与模型服务的连线；DSH 的外层模型请求、RAG 的查询 Embedding、重排和回答调用在正文与图 05 中分别解释。模型返回消息、完整日志和每一条底层存储读写没有全部展开。

`figures.json` 保存手工布局和关系数据；`build_diagrams.py` 可重建 HTML、SVG 和逻辑源。生成脚本只写本目录，不操作正式知识库。

当前交付使用 SVG 插图，不依赖额外安装 PNG 渲染组件。浏览器可直接打开，文档与图示都采用本机中文字体回退，无在线字体请求。
