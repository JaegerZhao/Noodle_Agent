复用时校验原 PDF、解析产物、页码证据和不可变构建记录，再登记为测试语料。没有重新调用 MinerU、视觉或原子笔记 Writer；原 next 库的活动指针未变。两篇笔记来自同一份神经网络 PDF，因此独立证据家族始终应计为 **1**，不能把两篇笔记包装成两份独立文档。

真实验收发现并修复了两个工程问题：首次发布前没有公开预留章节，导致模型误用原子章节 ID；模型把 `identity_key` 填进 `concept_id`，此前校验反馈不足以指导修复。现在目录包含待发布章节的稳定 ID，校验反馈明确列出合法 Concept UUID，并从检查点恢复成功。没有放宽 ID 或来源检查来让结果通过。

工程测试还发现了相同输入恢复时可能复用 WITHDRAWN Revision 的边界，现已要求重新发布，并加入回归。

## 小样本检索评测

人工设置 5 个正例问题，分别检查梯度下降/反向传播分工、学习率、输出层误差、隐藏层误差信号和权重梯度，期望命中指定的原子笔记。两篇原子笔记与两篇 Concept 的小语料上，Recall@20 为 **5/5**。

一次 Windows 暖进程测试中，使用已有索引、实时网络 Embedding、关闭重排：检索 p50 约 **179 ms**，五次样本的高分位上界约 **909 ms**。样本太少，不能作为稳定 p95、企业规模性能或多学科质量结论。后端一致性也只完成小语料对照，没有宣称达到大规模 ANN Recall@50 的设计目标。

独立模型审查不等于独立人工金标。尚未对全部内容做科学准确性评审；知识覆盖不足、跨学科消歧和复杂公式仍需扩大样本验收。
